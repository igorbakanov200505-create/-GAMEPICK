03 / OBS STUDIO

ВИДЖЕТЫ ДЛЯ ЭФИРА

Отдельные прозрачные окна для OBS: анимация, результат, тройной сценарий, таймер, история игр и голосование зрителей.

Размер источника 1280 × 720. Для локального сайта OBS должен работать на этом же компьютере. Ссылку с ID комнаты держи при себе.

OBS

Открой «Рандомайзер → OBS-оверлей», скопируй адрес и добавь в OBS как браузерный источник.

Клавиши

Пробел — вращать, Esc — выйти из полноэкранного режима, / — искать.

Пасхалки

Небольшие секретные эффекты спрятаны в интерфейсе. Например, логотип любит частые нажатия.
